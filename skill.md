## Project Rules

1. gunakan acuan style ui konsisten seperti pada menu pelanggan
2. gunakan konsep shadcn/ui sebagai komponen ui
3. gunakan tailwind css sebagai framework css
4. gunakan next js sebagai framework js
5. gunakan typescript sebagai bahasa js
6. gunakan prisma sebagai orm
7. gunakan mysql sebagai database
8. gunakan node js sebagai runtime js
9. gunakan pnpm sebagai package manager
10. jangan pernah menggunakan bahasa selain indonesia
11. jangan gunakan konsep rounded pada project ini
12. selalu buatkan konsisten setiap kali membuat komponen baru
13. jangan tambahkan icon pada project ini jika tidak di minta
14. jangan tambahkan deskripsi berlebih pada project ini
15. buatkan kode terbaik
16. jangan pernah meminta ijin untuk membuka browser

## finalisasi code
selalu cek apakah di terminal ada error atau tidak jika ada langsung saja perbaiki.
